\doxysubsection{Detailed Description}
Extracts assignments from the flow graph and writes results to files. 

This module is responsible for\+:
\begin{DoxyItemize}
\item Interpreting the flow graph after running the max-\/flow algorithm
\item Extracting valid assignments between submissions and reviewers
\item Identifying failed assignments (insufficient reviewers)
\item Writing results to output files 
\end{DoxyItemize}
