Constructs a graph for the assignment problem. 

The resulting graph follows this structure\+:
\begin{DoxyItemize}
\item Source node (id = -\/1)
\item Sink node (id = -\/2)
\item Submission nodes (is\+\_\+sub = true)
\item Reviewer nodes (is\+\_\+sub = false)
\end{DoxyItemize}

Edges\+:
\begin{DoxyItemize}
\item Source -\/\texorpdfstring{$>$}{>} Submission (capacity = Min\+Reviews\+Per\+Submission)
\item Reviewer -\/\texorpdfstring{$>$}{>} Sink (capacity = Max\+Reviews\+Per\+Reviewer)
\item Submission -\/\texorpdfstring{$>$}{>} Reviewer (capacity = 1 if domains match)
\end{DoxyItemize}

Matching rules depend on the Generate\+Assignments parameter\+:
\begin{DoxyItemize}
\item 1\+: Only primary domain/expertise
\item 2\+: Primary + secondary submissions vs primary reviewers
\item 3\+: Full matching (primary + secondary both sides)
\end{DoxyItemize}

The matching between submissions and reviewers is determined according to the Generate\+Assignments parameter and domain compatibility.
