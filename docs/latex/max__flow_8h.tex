\doxysubsection{Detailed Description}
Implementation of the Edmonds-\/\+Karp algorithm for maximum flow. 

This module provides functions to compute the maximum flow in a directed graph using the Edmonds-\/\+Karp algorithm.

The graph is assumed to represent a flow network where\+:
\begin{DoxyItemize}
\item \doxylink{classEdge}{Edge} weights represent capacities
\item \doxylink{classEdge}{Edge} flows are updated during execution 
\end{DoxyItemize}

Computes the maximum flow using the Edmonds-\/\+Karp algorithm. 

Repeatedly finds augmenting paths using BFS and augments flow along those paths until no more augmenting paths exist.

Algorithm steps\+:
\begin{DoxyEnumerate}
\item Initialize all flows to zero
\item While an augmenting path exists\+:
\begin{DoxyItemize}
\item Find the minimum residual capacity (bottleneck)
\item Augment flow along the path
\end{DoxyItemize}
\end{DoxyEnumerate}
