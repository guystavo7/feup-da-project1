Builds the graph used to solve the assignment problem. 

Constructs a graph for the assignment problem.

This function creates a bipartite graph between submissions and reviewers, connecting it to a source and sink to enable max-\/flow utilization.

The matching between submissions and reviewers is determined according to the Generate\+Assignments parameter and domain compatibility.
