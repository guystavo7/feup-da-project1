Detailed Description

Handles parsing of input files into local data structures.

This module reads structured input files describing submissions, reviewers, parameters, and control options, and converts them into our project's data structures.

Parses a CSV input file.

The file is processed line by line and divided into sections:

  • #Submissions
  • #Reviewers
  • #Parameters
  • #Control

Depending on the current section, the appropriate parsing function is used.
