◆ parse()

params parse ( string  path)

Parses the input CSV file and builds the params structure.

Parses a CSV input file.

The file is processed line by line and divided into sections:

  • #Submissions
  • #Reviewers
  • #Parameters
  • #Control

Depending on the current section, the appropriate parsing function is used.

Parameters
pathPath to the input file
Returns
params Struct containing all parsed data

complexity O(n), where n is the number of lines in the file

Note
Assumes the input file follows the expected format.
